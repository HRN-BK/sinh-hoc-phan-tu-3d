# 🧬 SHPT 3D: Sinh học Phân tử & Di truyền

Web học tương tác bằng mô hình 3D (three.js) cho môn Sinh học Phân tử & Di truyền, chương 1–6.

Mỗi bài trả lời đủ các câu:
- để làm gì;
- thiếu thì tế bào sao;
- nền tảng cần nhớ lại;
- cơ chế từng bước (đồng bộ với 3D);
- ứng dụng;
- phân biệt;
- bẫy dễ nhầm;
- tự kiểm tra.

Bộ tài liệu còn có 3 đề luyện chấm điểm tự động và một cheatsheet 4 mặt A4.

Chạy local: `python3 -m http.server` trong thư mục này rồi mở `http://localhost:8000`.

Mô hình 3D là hình minh họa đơn giản hóa, không đúng tỉ lệ thật.
